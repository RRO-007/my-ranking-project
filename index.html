📖 FIFA & Club SUM Calculation Methodology

Both National Teams and Clubs utilize an adapted Elo algorithm known as the SUM formula to update ratings following every daily match.

Formula: P = P_before + I * (W - W_e) Where: • P_before : Points prior to the match • I : Match importance weight (5 to 60) • W : Result (1.0 = Win, 0.75 = PSO Win, 0.5 = Draw/PSO Loss, 0.0 = Loss) • W_e : Expected outcome formula = 1 / (10^(-Δ / 600) + 1) (Δ = P_before(Team A) - P_before(Team B)) Dual Ranking Rules: • Live Rank : Computed dynamically daily by sorting updated Live Points (P). • Monthly Rank : Baseline official rank issued periodically by FIFA or governing body. • Position Shift: Diff = Monthly Rank - Live Rank (+2 means moved up 2 ranks).
